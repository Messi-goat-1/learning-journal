### 🛠️ What I'm building

**Kerneye**: one agent, one view to monitor your servers.

Many companies still juggle several monitoring tools: one for servers, one for apps, one for alerts.
Kerneye's goal is simple:

- **One agent** you install on your server
- **One interface** for both the system and its applications
- **Runs on your own server**: your data never leaves your company
- **Built for startups and mid-sized companies**

Kerneye is built on top of [Coroot](https://github.com/coroot/coroot), an open-source observability project.
Next on the roadmap: **adding a security layer**, so performance and security live in the same agent.
