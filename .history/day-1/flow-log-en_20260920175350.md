packet_tx / packet_rx	UInt64	عدد الحزم في الفترة
byte_tx / byte_rx	UInt64	عدد البايتات في الفترة

l4_byte_tx / l4_byte_rx	UInt64	بايتات طبقة النقل (L4)
total_packet_tx / total_packet_rx	UInt64	إجمالي الحزم منذ بداية التدفق
total_byte_tx / total_byte_rx	UInt64	إجمالي البايتات منذ بداية التدفق
10) طلبات L7 داخل التدفق

11) التأخير (Latency)
اسم العمود	النوع	الشرح الأصلي	التوضيح بالعربي
rtt	Float64	单位: 微秒	زمن الذهاب والإياب الكلي (RTT) بالميكروثانية
rtt_client	Float64	单位: 微秒	جزء RTT بين نقطة الالتقاط والعميل
rtt_server	Float64	单位: 微秒	جزء RTT بين نقطة الالتقاط والخادم
tls_rtt	Float64	单位: 微秒	زمن مصافحة TLS
srt_sum / srt_count / srt_max	Float64 / UInt64 / UInt32	max بالميكروثانية	زمن استجابة النظام (System Response Time): المجموع، العدد، الأقصى
art_sum / art_count / art_max	Float64 / UInt64 / UInt32	max بالميكروثانية	زمن استجابة التطبيق (Application Response Time)
rrt_sum / rrt_count / rrt_max	Float64 / UInt64 / UInt32	max بالميكروثانية	زمن الطلب/الرد (Request-Response Time)
cit_sum / cit_count / cit_max	Float64 / UInt64 / UInt32	max بالميكروثانية	زمن الخمول على العميل (Client Idle Time)

المتوسط = sum / count (مثل srt_sum / srt_count).

12) جودة الشبكة
اسم العمود	النوع	التوضيح بالعربي
retrans_tx / retrans_rx	UInt32	عدد الحزم المُعاد إرسالها

zero_win_tx / zero_win_rx	UInt32	مرات ظهور نافذة TCP بحجم صفر (المستقبل ممتلئ)
ooo_tx / ooo_rx	UInt32	حزم وصلت خارج الترتيب
ملاحظات مهمة
الأعمدة الأهم للتحليل: start_time، ip4_0، ip4_1، server_port، protocol، byte_tx، byte_rx، rtt، retrans_tx، close_type، status.
الفرق عن l7_flow_log: هنا مقاييس الاتصال (بايتات، تأخير، إعادة إرسال)، وهناك تفاصيل الطلبات (HTTP، SQL...).
الأوقات بتوقيت Asia/Shanghai، وأنت في مسقط (UTC+4)، فالفرق 4 ساعات.
أعمدة الضغط (T64, Gorilla, DoubleDelta) حذفتها لأنها تخص التخزين الداخلي.
